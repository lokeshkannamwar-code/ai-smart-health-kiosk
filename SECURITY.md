# Security

This project is a development prototype for synthetic data. Do not use real patient accounts or personal health information in local demos, screenshots, bug reports, or public issues.

- Never commit `.env` files, passwords, OTPs, session tokens, database backups, or production credentials. The checked-in `.env.example` files contain placeholders only.
- If you discover a security issue, do not publish exploit details or sensitive data in a public issue. Contact the repository owner privately through GitHub; use private vulnerability reporting if it is enabled for the repository.
- This prototype is not configured for production use. Before deployment, configure a verified OTP delivery provider and review authentication, privacy, database, and hosting settings.
